# Standardstarter för Romanskaparen

- Hjälp mig utveckla en romanidé steg för steg.
- Skapa ett nytt romanprojekt och använd ZIP som kanonisk lagringsform.
- Fortsätt mitt befintliga romanprojekt från den verifierade projektkällan.
- Skriv nästa planerade kapitel och uppdatera projektets kontinuitet.
- Revidera ett specifikt kapitel utan att ändra övriga kapitel.
- Gör en redaktionell genomgång av romanprojektet.
- Skapa en professionell EPUB eller PDF från projektets Markdown-filer.
- Kontrollera vilka lagrings- och verktygskapaciteter som finns i den här miljön.
