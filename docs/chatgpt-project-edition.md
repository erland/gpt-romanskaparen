# ChatGPT Project Edition

Project Edition är avsedd för långvarigt romanarbete i vanliga ChatGPT Projects.

## Rekommenderad modell

```text
Ett ChatGPT Project = en roman
Ett romanrepository = högst en roman
Flera chattar = samma kanoniska romanprojekt
```

Separata chattar kan användas för planering, kapitel, redaktion, research och export. Projektminne och chatthistorik ersätter aldrig manifest, revisionslogg eller projektfiler.

## Installation

Följ `distributions/project/INSTALL.md`, klistra in `PROJECT-INSTRUCTIONS.md` som projektinstruktion och ladda upp sex knowledge-filer samt projektbundlen. Starta sedan med `START-HERE.md`.

## Lagring

ZIP fungerar alltid som säker filbaserad fallback när filverktyg finns. GitHub eller annan extern lagring får användas endast när den aktuella användarens anslutning klarar läsning, skrivning, versionslåsning, återläsning och verifiering.

Åtkomst ska vara användarspecifik. En delad statisk nyckel med bred åtkomst är inte en godkänd distributionsmodell.

## Befintlig roman

Bifoga exakt den senaste verifierade projekt-ZIP-filen eller peka ut en verifierat tillgänglig extern källa. Behåll samma `project_id` och revision.
