# Arkiv för Romanskaparen 1.x

Romanskaparen 1.x låg som ett GPT-centrerat paket i repositoryts rot.

Den sista 1.x-bas som användes för 2.0-arbetet är commit:

```text
2bfe0c882d7d4a510aededb23f71a2302af20b5a
```

Där finns bland annat:

- `gpt-instructions.md`
- `conversation-starters.md`
- `knowledge-upload/`
- `templates/romanprojekt/`
- `project-template-bundle.md`
- äldre setup- och förändringsdokument

Filerna kopieras inte till ett aktivt arkivträd eftersom det skulle skapa parallella regelkällor. Git-historiken är det kanoniska arkivet. Aktiv utveckling sker under `core/` och `distributions/`.
