# Obligatorisk filhantering

Vid ändring av romanprojekt måste värden ge Python-körning, ZIP-läsning/-skrivning och persistent arbetsyta. Kör `project_integrity.py` före och efter ändring enligt bindande manual. Enbart tillgång till ett SKILL.md eller ett bifogat skript ger inte exekveringsförmåga. Om körmiljön inte kan materialisera eller köra skriptet: avbryt filändringen och redovisa begränsningen; inga påståenden om verifierad ZIP.
