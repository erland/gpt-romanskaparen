# Romanskaparen – ChatGPT Project Edition

Detta är distributionen för att använda Romanskaparen i ett vanligt ChatGPT Project.

Den rekommenderade modellen är:

```text
Ett ChatGPT Project = en roman
Ett kanoniskt romanprojekt = en ZIP eller en verifierad extern projektkälla
Flera chattar = olika arbetsområden för samma roman
```

Project Edition bygger på den gemensamma kärnan under `core/`. ZIP fungerar som fullständig filbaserad arbetsform när filverktyg finns. GitHub och andra externa anslutningar är villkorliga och får endast användas efter verifierat förmågetest.

## Innehåll

- `PROJECT-INSTRUCTIONS.md` – klistras in som Project Instructions.
- `START-HERE.md` – första prompt och onboarding i ett nytt romanprojekt.
- `INSTALL.md` – installationsanvisning.
- `knowledge/` – sex underlagsfiler från den gemensamma kärnan.
- `project-template-bundle.md` – komplett romanprojektmall och integritetsverktyg.
- `distribution-manifest.json` – maskinläsbar beskrivning av distributionen.

## Rekommenderade chattar

- Planering och romanbibel
- Kapitelproduktion
- Redaktion och kontinuitet
- Export och publicering
- Omslag och illustrationer

Chatt- eller projektminne ersätter aldrig romanprojektets manifest, revisionslogg och kanoniska filer.

## Kanoniska källor

Filerna i denna katalog är distributionsartefakter. Källorna finns under `core/` och ska senare byggas och valideras automatiskt.
