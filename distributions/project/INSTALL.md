# Installera Romanskaparen i ett ChatGPT Project

## 1. Skapa ett separat Project för romanen

Skapa ett nytt ChatGPT Project och döp det till romanens titel eller arbetstitel. Använd ett separat Project för varje roman.

## 2. Project Instructions

Kopiera hela innehållet i:

```text
PROJECT-INSTRUCTIONS.md
```

in i projektets instruktioner.

## 3. Projektfiler

Ladda upp exakt dessa sju underlagsfiler till projektet:

```text
knowledge/01-arbetsflode-och-nyborjarstod.md
knowledge/02-berattelsehantverk.md
knowledge/03-karaktarer-varld-och-kontinuitet.md
knowledge/04-genreguider.md
knowledge/05-projektstruktur-och-synk.md
knowledge/06-verktyg-och-lagringskapaciteter.md
project-template-bundle.md
```

Ladda inte upp `core/templates/romanprojekt/` fil för fil.

## 4. Starta första chatten

Öppna en ny chatt i projektet och använd prompten i `START-HERE.md`.

## 5. Rekommenderade verktyg

- Filhantering/Data Analysis – krävs för fullständigt ZIP-flöde, integritetskontroll och export.
- Bildgenerering – valfritt för omslag och konceptbilder.
- Webbsökning – valfritt för research.
- GitHub eller andra anslutningar – valfritt och endast efter godkänt förmågetest.

## 6. Befintlig roman

Bifoga den exakta senaste projekt-ZIP-filen eller peka ut en verifierbart tillgänglig extern projektkälla. Romanskaparen ska aldrig försöka återskapa projektet från chatt- eller projektminnet.

## 7. Flera chattar

Skapa gärna separata chattar för planering, kapitel, redaktion och export. Alla ska arbeta mot samma kanoniska romanprojekt och samma revisionskedja.

## Första test

1. Skapa ett litet nytt projekt i ZIP-läge.
2. Skriv kapitel 1 och skapa nästa revision.
3. Fortsätt i en ny projektchatt från den senaste ZIP-filen.
4. Kontrollera att rätt project-id och revision används.
5. Testa extern lagring först därefter, om verktyget faktiskt finns.
